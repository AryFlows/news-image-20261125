## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies the pre-rendered `entry.png` (1024×1024, standard library only, no network) to `/output/entry.png`. Run it twice and the bytes are identical.
